제조 데이터 분석불량 예측경진대회

사출성형 품질불량 사전예측 및 검사 우선순위

제6회 K-인공지능 제조데이터 분석 경진대회 (KAMP) · 3인 팀 · 데이터 전처리·검증 담당

  • 문제사출성형 공정 데이터로 최종검사 전에 불량을 예측하고, 검사 우선순위를 정하는 과제 (CN7·RG3 두 금형 데이터)
  • 역할데이터 진단, 전처리, 검증 설계, 팀 공용 데이터 구성, 보고서 작성
  • 방법2캐비티(LH/RH) 쌍 구조를 샷 단위로 병합 → 인접 샷 블록 그룹 교차검증 → 다중비교 보정 순열검정으로 신호 유무 판정 → 급변 경보와 캐비티별 검사 규칙으로 검사 우선순위 설계
  • 발견① 불량 신호는 우측(RH) 캐비티에 집중② 검증 방식에 따라 성능이 과대평가되는 누수 요인을 분해③ 높게 나온 초기 성능이 샷 단위 신호가 아니라 시기 구분 효과임을 확인하고 결론을 정정④ 파일별로 따로 표준화된 데이터를 직접 비교하면 생기는 착시를 발견 (표준편차 약 78배 차이)

성능 수치보다 검증의 정직성에 초점: 스스로의 오류까지 외부 자료로 교정하며 결론을 단계적으로 수정
